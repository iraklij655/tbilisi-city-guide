# თბილისი — აღმოაჩინე ქალაქი

სასწავლო ერთგვერდიანი გზამკვლევი თბილისის ღირსშესანიშნაობების, ნახევარდღიანი მარშრუტისა და პრაქტიკული რჩევების შესახებ.

## ტექნოლოგიები
- React — UI-ის კომპონენტებად დაყოფა და მდგომარეობის მართვა (`useState`, `useEffect`).
- TypeScript — კომპონენტების მონაცემებისა და ფუნქციების ტიპიზაცია.
- Tailwind CSS — ჩართულია Tailwind-ის build pipeline და გამოყენებულია utility კლასები (`min-h-screen`, `w-full`); კომპონენტების ინდივიდუალური დიზაინი დამატებით აღწერილია `src/style.css`-ში.
- Vite — განვითარების სერვერი და production build.
- HTML5 / CSS3 — სემანტიკური სტრუქტურა, Flexbox, Grid და responsive განლაგება.
- Git / GitHub — ვერსიების კონტროლი.

## გაშვება
საჭიროა Node.js-ის LTS ვერსია.

```bash
npm install
npm run dev
```

Production build-ის შესამოწმებლად:

```bash
npm run build
npm run preview
```

## ფუნქციონალი
- მობილურის ნავიგაციის მენიუ;
- ხედების კარუსელი: წინა/შემდეგი, ინდიკატორები, ავტომატური გადართვა და პაუზა;
- ფორმის ვალიდაცია სახელისა და ელფოსტის ველებისთვის;
- სექციებზე გადასვლა და კლავიატურისთვის განკუთვნილი skip link;
- reduced-motion პარამეტრის გათვალისწინება.

ფორმა დემონსტრაციულია: მონაცემები სერვერზე არ იგზავნება.

| 2 | React კომპონენტების შექმნა | Header, Slider, ContactForm და გვერდის სექციები |

## რისკები და კონტროლი
- მცირე ეკრანზე განლაგების დარღვევა — შემოწმდეს 375px, 768px და 1440px სიგანეებზე.
- არასწორი ფორმის მონაცემები — ცარიელი სახელი და არასწორი ელფოსტა ცალკე შემოწმდეს.
- მოძრაობისადმი მგრძნობელობა — ავტომატური სლაიდერი ითვალისწინებს `prefers-reduced-motion` პარამეტრს.
- პაკეტების ვერსიების ცვლილება — ინსტალაციის შემდეგ შეინახეთ `package-lock.json`.

## Git / GitHub ატვირთვა (სტუდენტმა უნდა შეასრულოს საკუთარ ანგარიშზე)
1. შექმენით GitHub-ზე ახალი ცარიელი repository სახელით `tbilisi-city-guide` (README-ის ავტომატური შექმნის გარეშე).
2. პროექტის საქაღალდეში გახსენით Terminal და შეასრულეთ:
```bash
git init
git add .
git commit -m "chore: initialize React TypeScript project"
git add README.md src/App.tsx src/main.tsx src/style.css src/tailwind.css
git commit -m "feat: build responsive Tbilisi city guide"
git branch -M main
git remote add origin https://github.com/USERNAME/tbilisi-city-guide.git
git push -u origin main
```
`USERNAME` ჩაანაცვლეთ თქვენი GitHub მომხმარებლის სახელით. თუ GitHub-ზე უკვე გაქვთ README ან სხვა ფაილები, ჯერ შეათანხმეთ ისტორია და არ გამოიყენოთ ზემოთ მოცემული ბრძანებები უცვლელად.

## ჩაბარებამდე სავალდებულო შემოწმება
- `npm install` — დამოკიდებულებების დაყენება.
- `npm run build` — TypeScript-ისა და production build-ის შემოწმება; წარმატების შემთხვევაში უნდა შეიქმნას `dist/`.
- `npm run dev` — გვერდის გახსნა ბრაუზერში.
- შეამოწმეთ 375px, 768px და 1440px სიგანეები, მენიუ, სლაიდერი და ფორმა.
- ზემოთ ჩამოთვლილი შემოწმებების რეალური შედეგები ჩაიწერეთ და მხოლოდ ამის შემდეგ მიუთითეთ, რომ ტესტირება წარმატებულია.

კოდის სტრუქტურა მომზადებულია Vite/React/TypeScript გარემოსთვის. საბოლოო გადაცემამდე გაუშვით `npm install` და `npm run build`; ასევე შეამოწმეთ გვერდი მობილურ და დესკტოპ ბრაუზერში. GitHub-ზე ატვირთვა შესრულებულად ჩაითვლება მხოლოდ `git push`-ის შემდეგ.
